# Security Policy

ALIV handles confidential legal and financial documents, so we treat security reports as a priority.

**Please do not open a public issue for a vulnerability.** Report it privately through GitHub's private vulnerability reporting: https://github.com/VenkataAnilKumar/ALIV/security/advisories/new.

Include:
- the affected version or commit,
- steps to reproduce,
- the impact you observed (for example, data leaving the device despite a Local only policy, or a file change without approval).

We will acknowledge your report, keep you updated while we work on a fix, and credit you in the advisory unless you prefer otherwise.
